Create mashup music randomly.

Steps guide

1.) download the code <br>
2.) install required libraries in requirements.txt<br>
3.) get the music files in your local, by downloading them (make sure the format is mp3 320 kbps)<br>
4.) put the files in folder with path "/content/songs" (this is the default path)<br>
5.) run the load_songs3 functions to load songs into the global variables<br>
6.) set the number of chunks you want in the mix_songs4 function (eg mix_songs(10) means 10 chunks will be selected for final mashup.<br>
7.) after hitting the mix_songs4() function, within few minutes, you will get the mashup stored in your local.<br>
